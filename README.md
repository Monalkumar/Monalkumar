### ☁️ CloudVault — Full-Stack SaaS Storage Platform

**CloudVault** is a full-stack cloud storage SaaS MVP designed around secure file management, access control, scalable APIs and cloud-based media storage.

> **MVP ready — currently evolving and being actively developed toward a more complete SaaS product.**

### 🏗️ Architecture

```text
                    ┌──────────────────────┐
                    │      Next.js App     │
                    │ React + TypeScript   │
                    └──────────┬───────────┘
                               │
                               ▼
                    ┌──────────────────────┐
                    │     API Layer        │
                    │ Auth • Validation     │
                    │ Business Logic       │
                    └──────────┬───────────┘
                               │
             ┌─────────────────┼─────────────────┐
             ▼                 ▼                 ▼
       ┌───────────┐     ┌───────────┐     ┌───────────┐
       │ MongoDB   │     │ Cloudinary│     │  Redis    │
       │ Metadata  │     │  Storage  │     │ RateLimit │
       └───────────┘     └───────────┘     └───────────┘
```

### 🔐 Core Features

* JWT-based authentication
* HTTP-only cookie based access token
* Secure authentication flow
* RBAC / authorization patterns
* Zod request validation
* Password hashing with bcrypt
* File upload and cloud storage
* MongoDB metadata management
* Public / private file sharing
* File rename and delete
* Ownership validation
* Cursor-based pagination
* Search functionality
* API rate limiting
* Redis-backed infrastructure
* Responsive Next.js application
* Production-oriented error handling
